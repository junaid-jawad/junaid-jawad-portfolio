# Junaid Jawad | Accounting Portfolio

A modern, responsive portfolio for Junaid Jawad, a Rutgers accounting student. It presents a concise professional introduction, an academic profile, experience with documented scope, organized skills, two detailed academic case studies, and a printable résumé.

**Live site:** https://mj947-blip.github.io/junaid-jawad-portfolio/  
**Repository:** https://github.com/mj947-blip/junaid-jawad-portfolio

## Project references

- [Job Costing & Financial Analysis](job-costing.html) — an Excel and PivotTable analysis of revenue, margins, manufacturing overhead, and cost variances across products and regions.
- [Cost-Volume-Profit Modeling](cvp-analysis.html) — a two-product-line Excel model for contribution margin, break-even, target profit, and scenario analysis.

The case studies are based on the academic work described in Junaid's résumé. Original course workbooks and employer records are not included. Project illustrations show accounting concepts rather than numerical project results.

## Résumé and accessibility

- [View the résumé](https://mj947-blip.github.io/junaid-jawad-portfolio/resume.html) and use **Print / save PDF** for a printable copy.
- Keyboard navigation, visible focus indicators, a skip link, accessible menu controls, and reduced-motion support.
- All content and navigation work without JavaScript; JavaScript adds the mobile menu, current-section navigation indicator, and print action.
- A custom animated hero, responsive project cards, and a cohesive dark green and mint design.\n- Motion respects reduced-motion preferences, and the résumé uses a clean print layout.\n- No external fonts, trackers, or runtime dependencies.

## Run locally

Open `index.html` in a browser, or serve this folder with any static HTTP server. There are no build tools or package dependencies.
